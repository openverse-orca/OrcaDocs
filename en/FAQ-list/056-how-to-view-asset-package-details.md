# How to view asset package details?

## Question
In the OrcaLab Asset Library, how can I obtain detailed information about an asset package, such as its author, number of included assets, total size, version notes, etc.?

## Answer

The OrcaLab Asset Library provides a detailed asset package information page where you can view all metadata including author, project, file size, version notes, and more. This helps you fully understand an asset package before subscribing.

## 📋 Viewing Asset Package Details

### Step 1: Access the Asset Library Page

Open your web browser and visit the OrcaLab Asset Library page:

[https://simassets.orca3d.cn/](https://simassets.orca3d.cn/)

### Step 2: Find the Target Asset Package

-   Find the asset package you're interested in through the Asset Library's "Asset Center" (or other categories) or through the search function. They are typically displayed as cards or in a list format.



### Step 3: Click to Enter the "Details" Page

-   In the asset package display area, there is usually a "Details" button or link. Click it to enter that asset package's dedicated detail page.



### Step 4: Review Detailed Information

On the asset package detail page, you will be able to see comprehensive information, typically including:

#### 1. **Basic Information**
-   **Asset Package Name**: The title of the asset package.
-   **Author**: The creator or uploader of the asset package.
-   **Project**: The project name this asset package belongs to.
-   **Number of Included Assets**: The count of individual 3D models or components in this asset package.
-   **Total Size**: The file size of the entire asset package, helping you estimate download time and required local storage space.
-   **Version**: The current version number of the asset package and possibly the update date.

#### 2. **Asset Description**
-   Detailed description of the asset package's content, usage, features, and applicable scenarios. This helps you understand the asset package's value.

#### 3. **Version Notes / Changelog**
-   Records changes between different versions of the asset package, such as new content, bug fixes, performance optimizations, etc. This is very helpful for tracking the evolution of the asset package.

#### 4. **Included Asset Files**
-   Typically lists all specific 3D model file names and types included in the asset package, possibly even with small preview images.

#### 5. **Other Related Information**
-   Subscription/unsubscription status.
-   If the asset package contains a scene, there may be a "Scene" tag indicator.
-   Creation date, last update date, etc.

## 💡 Details for Different Authors' Asset Packages

Asset package detail pages may vary by author. For example:
-   **This Author's Asset Package**: If you are the author of the asset package, the detail page may also show management operation buttons such as "Return to Drafts" and "Delete."
-   **Other Authors' Asset Packages**: Typically only show viewing information and "Subscribe/Unsubscribe" operations.



## 📋 Expand/Collapse Asset Package Contents

In the Asset Center list, some asset packages may have "+" and "-" buttons or icons.
-   Click "**+**": Expand the asset package to show the list of specific assets it contains.
-   Click "**-**": Collapse the asset package to hide the list of specific assets.


## ⚠️ Important Notes

### 1. **Information Completeness**
- The level of detail in asset descriptions and version notes depends on the asset package author's maintenance. Well-maintained asset packages typically provide detailed descriptions.

### 2. **Pre-Subscription Evaluation**
- Before subscribing to any asset package, it is strongly recommended to carefully review its detailed information to ensure it meets your project requirements and to evaluate its file size and number of included assets.

## 📝 Summary

Through the OrcaLab Asset Library's detail page, you can comprehensively understand all relevant information about an asset package, which is crucial for making informed subscription decisions. By leveraging this information, you can ensure you select the assets most suitable for your simulation projects.
