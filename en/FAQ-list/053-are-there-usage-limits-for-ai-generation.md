# Are there usage limits for AI generation?

## Question
The AI 3D asset generation feature in the OrcaLab Asset Library is very powerful. Are there usage limits for its Text-to-3D and Image-to-3D functions? What are the limits?

## Answer

Yes, the AI 3D asset generation feature in the OrcaLab Asset Library (including Text-to-3D and Image-to-3D) **has daily usage limits**. This is to fairly and reasonably allocate computing resources and aligns with OrcaLab's positioning as a free non-commercial product.

## 📋 Daily Usage Limits

### 1. **Specific Quotas**
- **Text-to-3D (Text Description)**: Each user has **5** generation attempts per day.
- **Image-to-3D (Image Reference)**: Each user has **5** generation attempts per day.

This means you can use the AI generation feature a **maximum of 10 times per day** (5 Text-to-3D + 5 Image-to-3D).

### 2. **Reset Time**
- Daily usage counts automatically reset at **midnight each day** (typically server time; refer to platform display for accuracy).

### 3. **Failed Generations Do Not Count**
- If a 3D asset generation attempt fails due to network issues, AI model errors, or improper input, it typically **does not consume** your generation quota.
- Only when the AI successfully returns a 3D model result is it counted toward your usage.



## 💡 Why Are There Usage Limits?

### 1. **Computing Resource Costs**
- 3D asset generation is a computationally intensive task requiring significant GPU computing power. Providing unlimited free generation would incur enormous server costs.

### 2. **Fair Usage**
- Limiting usage ensures all users can fairly enjoy the AI generation feature, preventing individual users from excessively occupying resources.

### 3. **Abuse Prevention**
- Effectively prevents users from exploiting the system through automated scripts or malicious behavior to farm large quantities of assets, maintaining a healthy platform ecosystem.

### 4. **Non-Commercial Positioning**
- As a free non-commercial version, providing reasonable quotas can meet learning, research, and personal creation needs while avoiding use for large-scale commercial production.

## 🛠️ Tips for Managing Usage Limits

### 1. **Optimize Your Descriptions or Images**
- Before each generation attempt, try to optimize your text descriptions to be more accurate and detailed.
- For Image-to-3D, choose high-quality reference images with clear subjects. This increases the success rate and satisfaction of each generation, reducing unnecessary attempts.
- See the tips section in [What is the difference between Text-to-3D and Image-to-3D?](FAQ-list/052-difference-between-text-to-3d-and-image-to-3d.md).

### 2. **Plan Usage Wisely**
- Plan the assets you need to generate for the day ahead of time and focus on using your daily quota efficiently.
- If you have a large number of asset generation needs, you can spread them across different days.

### 3. **Combine Manual Modeling with the Asset Library**
- For assets with simple structures or those requiring precise control, consider using traditional 3D modeling software (such as Blender, SketchUp) to create them yourself.
- Prioritize searching for existing assets in the Asset Library first; if they exist, there's no need to generate.

### 4. **Upgrade to OrcaStudio Enterprise Edition**
- If your workflow requires **high-frequency, large-scale, commercial-use** AI 3D asset generation, OrcaLab's free quota will not suffice.
- The OrcaStudio Enterprise Edition may offer higher quotas, more powerful generation capabilities, or customized services. Contact SongYing Technology for details.

## 📝 Summary

OrcaLab's AI 3D asset generation feature sets a daily free usage limit of 5 attempts each for Text-to-3D and Image-to-3D, totaling 10 per day. This is designed to balance user needs with platform resources. Users should use these quotas wisely and improve generation efficiency by optimizing inputs. For commercial or large-scale needs, consider the OrcaStudio Enterprise Edition.
