# What is the difference between OrcaLab and OrcaStudio Enterprise Edition?

## Question
What is the difference between OrcaLab and OrcaStudio Enterprise Edition? Which one should I choose?

## Answer

OrcaLab is the lightweight version of OrcaStudio Enterprise Edition. There are significant differences between the two in terms of feature positioning, applicable scenarios, and usage limitations:

### Feature Positioning Comparison

| Feature | OrcaLab (Lightweight) | OrcaStudio (Enterprise) |
|---------|------------------|---------------------|
| **Target Users** | University faculty/students, individual learners | Enterprise users, commercial projects |
| **Use Cases** | Teaching, learning, non-commercial research | Commercial development, production projects |
| **Feature Completeness** | Core feature experience version | Full feature version |
| **Technical Support** | Community support | Enterprise-grade technical support |

### Key Differences

#### 🎯 Usage License
- **OrcaLab**: Free to use, non-commercial purposes only
- **OrcaStudio**: Commercial license, supports commercial project development

#### 🛠️ Feature Scope
- **OrcaLab**:
  - Basic simulation functionality
  - Lightweight Asset Library
  - Simplified operation interface
  - Core training workflow experience

- **OrcaStudio**:
  - Complete simulation capabilities
  - Enterprise-grade asset management
  - Advanced development tools
  - Complete MLOps pipeline

#### 💼 Service & Support
- **OrcaLab**:
  - Documentation support
  - Community forum
  - GitHub open-source examples

- **OrcaStudio**:
  - Dedicated technical support
  - Customized services
  - SLA guarantees
  - Training services

### Selection Guide

#### Choose OrcaLab when:
- 🎓 **University Teaching**: Course experiments, student assignments
- 📚 **Personal Learning**: Exploring robot simulation technology
- 🔬 **Academic Research**: Non-commercial research projects
- 🔍 **Technology Evaluation**: Understanding Orca product capabilities

#### Choose OrcaStudio when:
- 🏭 **Commercial Projects**: Commercial license required
- 🚀 **Product Development**: Building commercial products
- 🎯 **Enterprise Applications**: Large-scale deployment needs
- 💪 **Full Features**: Need a complete simulation platform

### Upgrade Path
OrcaLab provides users with a complete upgrade path:
1. **Experience Phase**: Use OrcaLab to become familiar with core features
2. **Evaluation Phase**: Validate technical feasibility and business value
3. **Upgrade Phase**: Upgrade to OrcaStudio based on business needs

### Technical Compatibility

Both versions maintain technical architecture compatibility:
- **Data Formats**: Unified asset and configuration formats
- **API Interfaces**: Consistent programming interface design
- **Development Tools**: Same development environment and toolchain

This design ensures a smooth migration from OrcaLab to OrcaStudio.
