# Is OrcaLab free to use? What are the usage limitations?

## Question
Is OrcaLab free to use? What specific limitations and restrictions apply during use?

## Answer

Yes, **OrcaLab is completely free** to use, but there are clear usage limitations and conditions.

## Free Usage Policy

### ✅ Completely Free
- **Software**: OrcaLab software is completely free to download and install
- **Core Features**: All basic simulation features are free to use
- **Asset Library**: Basic Asset Library is free to access and subscribe
- **Technical Support**: Documentation and community support are completely free

### 💎 Free Feature Scope

#### Simulation Features
- High-fidelity physics simulation engine
- 3D scene editing and management
- Robot training environment setup
- VR data collection functionality

#### Asset Library Services
- 6 major asset categories free to use
- AI-generated 3D assets (limited quota)
- Asset search and subscription
- Personal asset management


## Usage Limitation Details

### 🚫 Commercial Use Restrictions (Important)

**Strictly Prohibited Commercial Uses**:
- Commercial product development
- Profit-generating projects
- Enterprise production environments
- Paid service provision
- Commercial software development
- Enterprise training (paid)

**Consequences of Violation**:
- Account may be banned
- Legal liability
- Loss of usage rights

### 🎯 Permitted Use Cases

**Compliant Non-Commercial Scenarios**:
- 🏫 Teaching and research activities
- 📚 Personal learning and skill development
- 🔬 Academic research and paper publication
- 🎓 Student assignments and capstone projects
- 🔍 Technical evaluation and product trial

### 📊 AI Generation Feature Limits

**Daily Usage Quota**:
```
Text-to-3D: 5 times per day
Image-to-3D: 5 times per day
Total: 10 generation attempts per day
```



**Quota Notes**:
- Resets at midnight daily
- Failed generations do not count toward the quota
- Paid quota increases are not currently supported

### 💾 Resource Usage Limits

#### Storage Limits
- **Local Storage**: Depends on user's hard drive space
- **Cloud Assets**: Reasonable limits on personal asset storage
- **Asset Versions**: Limited historical versions retained

#### Performance Limits
- **Concurrent Simulation**: Single simulation instance recommended
- **Complex Scenes**: Constrained by local hardware performance
- **Network Bandwidth**: Asset download speed affected by network conditions

## Terms of Use Requirements

### 📋 User Agreement
Using OrcaLab requires:
- Read and accept the User Agreement during registration
- Comply with the Privacy Policy
- Commit to non-commercial use only
- Do not maliciously abuse system resources

### 🔐 Account Management
- One email per account
- Do not share accounts with others
- Do not create multiple accounts to circumvent limits
- Account information must be truthful and valid

## Technical Support Scope

### ✅ Support Provided
- **Documentation Support**: Complete user documentation
- **Community Forum**: User discussion and problem-solving
- **Open-Source Examples**: GitHub code repositories (e.g., OrcaPlayground/OrcaManipulation)
- **Basic Q&A**: Frequently asked questions

### ❌ Support NOT Provided
- One-on-one technical support
- Custom development services
- SLA guarantees
- Enterprise-grade training services

## Upgrading to Enterprise Edition

If you need commercial use or more powerful features:

### 🚀 OrcaStudio Enterprise Edition Benefits
- **Commercial License**: Supports commercial projects
- **Full Features**: Complete enterprise-grade functionality
- **Dedicated Support**: One-on-one technical support
- **Custom Services**: On-demand custom development
- **SLA Guarantees**: Service Level Agreements

### 💡 Upgrade Considerations
Consider upgrading when:
- Commercial use is required
- Enterprise-grade technical support is needed
- Higher performance and stability are needed
- Custom feature development is needed

## Compliance Recommendations

### ✅ Recommended Practices
1. **Clarify Purpose**: Confirm your use case complies with non-commercial requirements
2. **Respect Quotas**: Use AI generation features responsibly
3. **Respect Copyright**: Do not distribute or commercially use generated assets
4. **Active Feedback**: Participate in community building, report issues

### ⚠️ Important Notes
1. **Boundary Awareness**: Clearly understand the line between commercial and non-commercial use
2. **Resource Conservation**: Use system resources responsibly, avoid waste
3. **Safe Usage**: Protect account information, pay attention to network security
4. **Version Updates**: Stay informed about software updates and policy changes

OrcaLab's free strategy aims to enable more users to access and learn robot simulation technology, but users must strictly comply with usage limitations to ensure compliant use.
